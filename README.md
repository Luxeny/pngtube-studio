# PNGTube Studio

Студия анимированных PNG-аватаров для стримеров.

Собирайте персонажа из слоёв, настраивайте состояния и переключайте их горячими клавишами, оживляйте аватар голосом через микрофон и выводите картинку в OBS через окно хромакея.

**[Скачать для Windows](https://github.com/Luxeny/pngtube-studio/releases/latest/download/PNGTube-Studio-Setup.exe)** · [Все версии](https://github.com/Luxeny/pngtube-studio/releases)

## Возможности

- **Слои и состояния** — персонаж из GIF и картинок, несколько состояний с горячими клавишами.
- **Молчание и разговор** — для каждого состояния две дорожки: когда вы молчите и когда говорите.
- **Микшер** — устройство ввода, шумодав, порог громкости, чувствительность и задержка.
- **Таймлайн** — разрезайте клипы, зацикливайте, задавайте длительность и добавляйте звуки.
- **Эффекты** — дрожание, тряска, подпрыгивание, волна и глитч.
- **Корректировка** — прозрачность, насыщенность, оттенок, температура, контраст, свет и тени.

## Вывод в OBS

1. В OBS добавьте источник «Захват окна» и выберите окно «PNGTube Studio — Chromakey».
2. Правый клик по источнику → «Фильтры» → добавьте «Хромакей» (цвет — зелёный).
3. Окно работает само по себе: редактор можно закрыть, трансляция продолжится.

## Установка

Скачайте установщик и запустите его. Если Windows покажет окно «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с новыми приложениями, у которых пока нет цифровой подписи.
